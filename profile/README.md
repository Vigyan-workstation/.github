## Technical Philosophy

Vigyan pairs domain-specialized Small Language Models (SLMs) with a deterministic Computer Algebra System (SymPy CAS) and local multiphysics engines.

While generative neural networks decompose physical problems into mathematical formulations, stochastic decoders are inherently prone to arithmetic and algebraic errors. Vigyan guarantees absolute mathematical truth by executing all calculus, differential equations, and proofs through an in-process, sandboxed Computer Algebra System AST kernel.

* **Air-Gap Sovereign Execution**: Operates 100% offline with zero telemetry, zero analytics, and zero external cloud API egress.
* **Deterministic Symbolic Verification**: Eliminates hallucinated calculus, ODEs, and scientific constants via formal CAS grounding.
* **Resource-Governed Runtime**: Engineered to run smoothly on standard consumer hardware (< 2 GB RAM footprint) without discrete GPUs.

## Flagship Workstation: Vigyan Pro v5.0.7

The flagship workstation is actively developed and maintained in **[Vigyan-workstation/vigyan-pro](https://github.com/Vigyan-workstation/vigyan-pro)**.

### 1-Click Multi-OS Installation

#### Linux (Debian / Ubuntu / Pop!_OS / Mint)
```bash
# Download official release package & install
wget https://github.com/Vigyan-workstation/vigyan-pro/releases/download/v5.0.7/vigyan-pro_5.0.7_amd64.deb
sudo apt install ./vigyan-pro_5.0.7_amd64.deb

# Launch workstation
vigyan-pro
```

#### Linux Portable Archive (Arch, Fedora, openSUSE, RHEL)
```bash
wget https://github.com/Vigyan-workstation/vigyan-pro/releases/download/v5.0.7/vigyan-pro_5.0.7_linux_x86_64.tar.gz
tar -xzf vigyan-pro_5.0.7_linux_x86_64.tar.gz
cd vigyan-pro-linux && ./vigyan-pro
```

#### macOS (Apple Silicon M1/M2/M3/M4 & Intel 64-bit)
```bash
wget https://github.com/Vigyan-workstation/vigyan-pro/releases/download/v5.0.7/vigyan-pro_5.0.7_macos_universal.tar.gz
tar -xzf vigyan-pro_5.0.7_macos_universal.tar.gz
cd vigyan-pro-macos && ./vigyan-pro
```

#### Windows (Windows 10 & 11 64-bit Portable)
Download the standalone `.zip` archive from [Releases](https://github.com/Vigyan-workstation/vigyan-pro/releases/tag/v5.0.7), extract, and double-click `Vigyan-Pro.bat`.
